# 角度旋轉與三角函數正負變化

當角度旋轉後，點在單位圓上的位置會改變。請依下列步驟思考（本練習**不**使用 90°、270° 旋轉，避免餘函數轉換）：

1. **觀察象限**：旋轉前、旋轉後各在第幾象限？
2. **判斷座標**：要化簡的函數由哪個座標決定正負？
   - $\sin$ → **y** 座標（$y/r$）
   - $\cos$ → **x** 座標（$x/r$）
   - $\tan$ → **x 與 y** 座標（$y/x$，兩者都變號時比值不變）
3. **座標是否變號**：旋轉後，x、y 的正負與旋轉前相比，有沒有改變？
4. **決定負號**：依上一步結果，判斷最後要不要加負號。

# 解題提醒

旋轉 $180°$（或 $180°$ 的奇數倍）→ x、y **都變號** → $\sin$、$\cos$ 變號，$\tan$ **不變**

旋轉 $360°$（或 $360°$ 的整數倍）→ x、y **都不變** → 三角函數值與旋轉前相同

$180° - \theta$ 與 $\theta$ 互為補角 → x **變號**、y **不變** → $\cos$ 變號，$\sin$ 不變
