# 第一部分：正弦定理

正弦定理：$\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C}$

:::

:::question

answer:
b = 6\sqrt{3}

# 第三部分：綜合應用

下列各題需判斷適用正弦定理或餘弦定理，或兩者搭配使用。

:::figure source=file
path: figures/sine-cosine-law/q11.svg
alt: △ABC，已知 A=30°、b=6、c=6√3
:::

在 △ABC 中，已知 $A = 30°$，$b = 6$，$c = 6\sqrt{3}$。

(1) 先用餘弦定理求 $a$。  
(2) 再用正弦定理求 $B$。

:::question

$B =$ {{blank}}°

answer:
a = 6 \\
B = 30°
:::
